# 라이더스팟 게이미피케이션 v1 — 실행 명세
목표: 지도/GPS·배달 업무·커뮤니티의 기존 동작을 그대로 유지하면서 운행 완료 후 기록을 돌아보는 시각적 즐거움을 추가한다.

## 경험 설계
- 내 정보: 기존 운행 기록에서 계산한 레벨, XP 바, 칭호, 업적 배지 도감. 새 탭은 만들지 않는다.
- 타임라인: 운행을 마친 날짜의 결과 카드(그날 운행 시간/거리, +XP, 새 업적). 개별 운행 종료 직후 같은 카드 표시.
- 비주얼: 딥그린·웜오렌지·미색을 사용해 지도 경로 모티프, 경험치 바, 배지 메달, 짧은 완료 애니메이션. reduced-motion 준수.
- 안전: 지도/운행 중에는 포인트·보상 팝업·효과음을 보이지 않는다. 운행 거리·속도·배달 건수로 반복 XP를 지급하지 않는다.

## 불변 조건
- 실제 완료된 운행 기록만 점수 계산에 사용한다. 시간대는 Asia/Seoul이다.
- 서로 다른 완료 기록 일수에 대해서만 하루 25 XP. 동일 날짜 복수 운행은 추가 XP 없음.
- 업적 최초 해금 시에만 15 XP (완료 일수 1/3/7/30, 기존 누적 100km). 거리는 수집형 뱃지만 사용한다.
- 진행 중 운행, 중복 ID, 잘못된 날짜, 음수/NaN 거리, 서버 동기화 반복은 보상에 영향을 주지 않는다.
- 사용자 GPS 좌표/SQLite/API/Supabase 스키마를 수정하거나 게임 상태를 서버로 전송하지 않는다.
- 모든 진행 상황은 저장된 운행에서 순수 계산한다. 기록 삭제 시 해당 기록은 보상 계산에서 빠진다.
- 로그인 없이 기기에 남아 있는 운행 기록도 계산하며 경로 좌표를 외부로 전달하지 않는다.

## 검증 및 출시
1. 순수 단위 테스트: 완료/진행 중/중복/잘못된 데이터/시차/선행 업적/시간 역행/불변성.
2. CSS/렌더링 테스트: 320·360·390·430px, reduced motion, 가로 넘침·지도 동작·기존 UI 영향.
3. GPS 브리지 및 SQLite 오프라인/저장/재생 기존 회귀 테스트 통과.
4. Cloudflare 별도 버전 미리보기로 검증 후 운영 트래픽 전환. 검증 실패 시 배포 금지.
5. 네이티브 APK 변경이 없으면 재빌드하지 않는다.

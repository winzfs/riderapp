# RIDERSPOT / MY YEAR — QUIET GRID
아트 디렉션, 와이어프레임 및 구현 명세 | 2026-11-23 | v2

## 1. 크리에이티브 브리프
**한 사람의 1년을 조용한 데이터 포스터로 표현한다.**
기록은 장식의 배경이 아니라 디자인의 주인공이다. 자연 풍경, 식물, 입체적인 그라데이션, 마스코트, 무의미한 아이콘 및 반복 카드에 의존하지 않는다.

스타일: Contemporary art exhibition catalogue + Swiss editorial grid + Quiet minimal product UI.
전환 전 UI의 문제: 4개 요약 카드 + 12개 월 카드 + 강조된 캡슐 토글이 동일한 시각적 무게로 경쟁한다. 테두리와 연한 녹색 바탕의 반복 때문에 캘린더의 정보 패턴이 작품처럼 보이지 않는다.

타이포: Pretendard / SUIT / Apple SD Gothic Neo / Noto Sans KR / system sans. 도록 문구 및 인덱스에는 10px 대문자 트래킹만; 한글 본문에 과도한 세리프를 강제하지 않는다.
- 큰 연도: 모바일 41–55px, 넓은 화면 최대 65px, 축소된 자간.

- 수치: 18–27px, tabular numbers.
- 부제 및 레이블: 10–12px.
- 데스크톱 본문 좌우 28–36px / 모바일 19px.
- 구분선 1px, 섀도우는 전체 다이얼로그에만 약하게.
- 모서리: 월별 캘린더 카드 0px(카드 삭제), 날짜 셀 2.5px, 월간 날짜 5px.

## 4. 컴포넌트 규칙
- 상단: 브랜딩 1행 + 닫기 버튼. 복잡한 헤더 장식 금지.
- 히어로: 좌측 제목 / 우측 연도 셀렉터. 연도가 페이지의 대표 그래픽 역할.
- 메트릭: 배경색 없음 / 분할선 + 숫자 위계.
- 기간 전환: 탭 아래 2px 밑줄. 필이나 그림자로 강조하지 않음.
- 연간 그리드: 모바일(<=559px) 2열, 화면 560px 이상 3열.
- 날짜 타일: 월 실제 시작 요일을 반영한 7열. 셀 사이 간격 3–4px, 3단계 강조색.
- 월간 상세: 같은 타이포 및 선의 리듬, 현재 날짜 표시, 터치 최소 높이 43px.
- 연도/월/일 모두 키보드 및 접근성 레이블 유지.
- 간결한 전환만 제공. prefers-reduced-motion에서 애니메이션 비활성화.

## 5. 그대로 유지해야 할 데이터 계약
- POST/UPDATE/DELETE 없음. 읽기 전용.
- 인증 사용자 `user_id`와 Supabase RLS에 의해 격리.
- `trips`: started_at, ended_at, distance_km. 완료 운행만.
- `rider_earnings`: work_date, gross_won, gross_entered, deliveries. gross_entered=false 제외.
- `rider_auto_deliveries` 별도 가산 금지 — 이중 수익 방지.
- 날짜는 Asia/Seoul 기준. 서버에 저장된 값은 수정하지 않음.
- 기록이 없는 날은 자동으로 휴무로 표시하지 않음.
- 기존 지도, GPS, 운행 종료, 수익 입력, 정비와 저장 구조는 변경하지 않음.

## 6. 기술 구성
- `src/year-calendar-bridge.js`: 기존 조회 로직 유지, 연간/월간 DOM 구조의 타이포 위계 변경, CSS v2 포함.
- `src/year-calendar-art-v2.css`: 단일 디자인 소스 파일. 앱용 bridge에도 포함돼 있으므로 다음 업데이트는 두 파일 동기화 필요.
- 배포는 별도 검증 후 edge gateway의 `YEAR_SCRIPT` 교체 + 캐시를 고려한 v2 asset URL 변경.
- 설치된 PWA가 이전 HTML을 들고 있어도 이전 에셋 조회를 계속 지원해야 함. 현장 운행 중 강제 새로고침 금지.

## 8. 운영 반영 결과 (2026-11-23)
- 운영 Worker `rider-spot`에 Quiet Grid v2 반영 성공. 운영 주소 `https://rider-spot.jazzhjm.workers.dev/`.
- URL `/rider-spot-my-year-v2.js`를 같은 출처에서 제공하며, 소스는 커밋 `5d94b4217132964575438bf2bb732f7b6d95d61a`에 고정된 jsDelivr 정적 자산으로부터 가져옴.
- 신규 파일 로드 실패 시 기존의 저장된 v1 스크립트로 폴백. 과거 `/rider-spot-my-year-v1.js` 라우트는 그대로 유지.
- 메인 앱 번들 `82c20b027c23`, recovery guard, OAuth 관련 분기와 ASSETS/DESIGN/LEGACY 서비스 바인딩 유지.
- Cloudflare Browser Rendering에서 운영 루트 로딩, 수익 탭 내 캘린더 버튼, 다이얼로그 열림, `rs-year-v2-style` 로딩, 비로그인 안내를 검증함.
- 실제 로그인 사용자의 데이터 합계 검증과 모바일 기기별 스크린샷 비교는 수행되지 않았으므로 별도 현장 확인이 필요함.
- 임시 테스트 Worker `rider-spot-urban-preview`는 이전 스크립트와 서비스 바인딩으로 원상 복구.
- 재배포 시 외부 CDN 참조가 필요함. 추후 앱 에셋에 함께 번들링하면 외부 의존성을 줄일 수 있음.

# RiderSpot UI/UX v33 — 적용 범위 및 검수 기록

기준: `design/mobile-layout-v32` (c8f9156). 작업 브랜치: `design/riderspot-uiux-plan-20261123`.
첨부 기획안의 기능 우선순위와 기존 API/저장/GPS/수익·정비 원본 유지 원칙을 따름.

## 소스 변경
- 공통 색과 하단 5탭 선택 표시의 위계, 48px 목표 터치 영역, 모션 축소
- 수익: 목표 대표 숫자/중복 제거, 월말 잔여일 상한 및 0일 예외, 장부 검색 조건, 결산 날짜, 정산 액션, 분석 주간 눈금·전체 레이블
- 내 바이크: 차량·모델 중복 제거, 알림 텍스트 요약, 부품판 3×2 고정, 타일별 TalkBack 거리 읽기
- 타임라인: 업무일 표시 및 작은 GPS 시작·종료 표지(기존 두 앵커/PNG 경로는 변경하지 않음)
- 동네·지도: 피드 밀도, 지도 동작 버튼 터치·조작 영역
- 업무 도구: 비상 연락처 문장 교정

### 중요한 병합 전 점검
최근의 `feature/riderspot-income-diagnostic`, `fix/native-route-style-load-20261123`,
`fix/trip-quota-safe-finalize-20261123`는 별도 이력이다. 이 PR 자체가 이들의
기능을 배포 환경에 자동 병합하지 않는다. 실제 Android 빌드에선 해당 변경사항이
포함된 동일 기준 통합 브랜치가 필요하다.

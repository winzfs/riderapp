# 라이더스팟 — 정비 아이콘 Symbol System 02

목표: **기호를 먼저 보고 부품을 알아보고, 필요할 때만 글자를 읽는 정비 화면.**

- **하나의 실루엣:** 실물을 묘사하지 않고 가장 알아보기 쉬운 형태만 남긴다. 광택·그라데이션·그림자·장식을 배제한다.
- **절제된 세 가지 색:** 먹색 #263831 중심, 차분한 회색으로 구조 표현, 테라코타 #C76F45는 작은 식별 신호에만 사용한다.
- **동일한 그리드:** 투명 배경, 고정 여백, 96×96px 셀 10종. 5열×2행 PNG 아틀라스(480×192px).
- **부품 식별:** 오일(용기+물방울), 앞 타이어(포크), 뒤 타이어(축), 브레이크(디스크+캘리퍼), 구동벨트, 에어필터, 배터리, 점화플러그, 냉각수, 기타(렌치).
- **의미와 조작은 UI에서:** 텍스트·선택 상태·소모품 임박 알림은 기존 UI가 맡는다. 이미지에 글자나 배경을 합치지 않는다.
- **성능:** 10개 PNG 요청 대신 하나의 팔레트 PNG(약 4KB). 번들러가 data URL로 포함해 네트워크 요청·WebView 지연이 없다.

대상: 부품 선택 / 소모품 현황 / 부품 관리 모달 / 정비 이력.
정비 저장 및 계기판 저장 로직은 변경하지 않는다.

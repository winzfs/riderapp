# 라이더스팟 APK 빌드
이 브랜치는 기존 riderapp 앱과 별개로 라이더스팟 Android 테스트 APK를 생성합니다.
소스 압축본: rider-spot-android/source.tar.xz
GitHub Actions > Rider Spot Native APK > Artifacts > RiderSpot-Android-1.0.0-debug 에서 파일을 받아 설치합니다.
Android 전경 GPS 서비스는 운행 기록을 위한 것이며, 백그라운드 타 라이더 위치 공유는 지원하지 않습니다.
GitHub 브랜치 main은 변경하지 않았습니다.

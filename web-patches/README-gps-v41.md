# 라이더스팟 GPS v41 — 실시간 타임라인 복구

운행 중 지도 동선이 비어 보이는 오류를 줄이기 위한 웹 패치. Android v1.0.6의 `RiderSpotHost`를 이용해 기기 SQLite에서 수용한 위치 좌표를 3초 간격으로 직접 확인하고, React 타임라인 상태에 병합한다. React `watchPosition` 구독 유무에 의존하지 않는다.

- 운행 중 GPS 경로는 기기에만 저장한다. Supabase 업로드는 기존 `운행 종료` 흐름을 그대로 따른다.
- 이전 브리지 메시지는 기존 처리기로 전달한다. `id >= 900000000` 범위로 별도 요청을 분리하며 요청 타임아웃 6초.
- 이미 누락된 좌표도 최초 조회 때부터 복원하며, 기록 간격이 긴 구간은 실제 이동하지 않은 도로를 그리지 않고 끊는다.
- GPS 수신 지연, 서비스 미시작, 마지막 SQLite 저장 시각을 타임라인에 표시한다.
- 1개만 들어온 구간은 지도에 점으로 표시한다. 같은 시간에 받은 중복 GPS 표본은 더 정확한 것을 유지한다.
- 페이지가 열린 상태에서 GPS 서비스가 시작되지 않았다면, 알림에서 종료하지 않은 운행에 한해 사용자에게 부여된 앱 위치 권한으로 재시작을 시도한다.
- 구글 로그인, 도로 보정, 정비 화면과 기존 Supabase 데이터는 건드리지 않는다.
- 적용 시간: 2026-11-16 13:39:05 UTC, Cloudflare Worker `rider-spot`, 버전 `bab341be-37db-4e7f-88f0-4e0177180d52`.

`rider-spot-v41-deploy.js`는 최초 v40 배포본에만 적용되므로 동일 패치를 재배포하기 전에 버전 조건을 확인해야 한다. Worker 전체 프리앰블과 Google OAuth 함수를 보존하는 배포 보호 조건 포함.

실기기에서 실제 GPS 수신 품질과 장시간 백그라운드 동작은 아직 검증 전이며, Android 서비스에 유효 좌표가 전혀 들어오지 않는 기기 환경은 배너로 상태를 알려주지만 경로 자체를 생성할 수는 없다.

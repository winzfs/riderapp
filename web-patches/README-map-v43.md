# 라이더스팟 v43 지도 경로 표시 개선 (2026-11-16)

웹 UI를 Cloudflare Worker `rider-spot`에 직접 배포한 작업입니다. 별도 APK 재설치가 필요하지 않습니다.

- 타임라인 주행 지도에 현재 위치를 청록색 점·화이트 테두리·오렌지 윤곽으로 크게 표시하며, `◎ 내 위치` 버튼으로 확대·이동합니다.
- GPS 원본(SQLite, Supabase)을 고치거나 삭제하지 않고 **화면 렌더링 경로**에서 정차 중 25초 이상, 24m 이내에 모인 표본을 중심점으로 묶어 복잡한 지그재그 선을 줄입니다.
- 같은 도로 구간을 재통과하면 메인 청록 경로 **바깥쪽에** 오렌지 얇은 레일을 그립니다. 2회 = 1겹, 3회 = 2겹, 4회 이상 = 3겹. 반복 판정은 좌표 19m 이내, 경로 방향 유사도·시간 차 120초 이상·순간 이동 누계 160m 이상 등의 기준을 사용합니다.
- 일반 도로 맵 매칭 기능은 기존대로 유지하며, 재통과 표시는 정확한 GPS 노선에 대한 추정 시각화입니다.
- 기존 OAuth·GPS 상태 및 운행 복구·운행 기록 종료 후 동기화는 수정하지 않았습니다.

관련 파일:
- `rs43_algorithms.js`: 경로 정리와 재방문 감지, 겹선 그리기 함수.
- `rs43_algorithms.test.cjs`: 6개 로직 자동 테스트.
- `rs43_deploy.js`: 운영 Worker 배포용 dry-run 안전 검사 스크립트. 코드의 `if(true)return {dryRun:true,...}`을 검증 완료 후 `false`로 전환할 때에만 실제 배포합니다. **가장 최근 운영 Worker 소스를 읽어 OAuth 프리앰블을 보존해야 합니다.**
